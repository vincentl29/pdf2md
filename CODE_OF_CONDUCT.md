# Code de conduite

## Contexte

**pdf2md** est un projet personnel développé et maintenu par une seule personne.
Il n'y a pas de communauté de contributeurs actifs, pas d'équipe de modération,
et pas de processus de gouvernance collective.

## Pour les utilisateurs et personnes qui signalent des problèmes

Toute remontée (bug, suggestion, question) est la bienvenue. Le projet est géré
bénévolement et dans le temps disponible ; les réponses peuvent prendre du temps.

Pour contacter le mainteneur : **pdf2md@leopold.bzh**

## Pour les éventuelles contributions externes

Si vous souhaitez contribuer (pull request, traduction, documentation), les
échanges doivent rester respectueux et constructifs. Les contributions non
sollicitées ou hors sujet peuvent être refusées sans justification détaillée.

## Licence et droits

Le code est distribué selon les termes de la licence indiquée dans le dépôt.
Aucune cession de droits supplémentaires n'est accordée au-delà de ce qu'elle
prévoit.
